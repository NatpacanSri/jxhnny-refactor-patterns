# Repository Agent Instructions

Use the Jxhnny Refactor Patterns guide for frontend refactors:

- Read `.agent-instructions/jxhnny-refactor-patterns/SKILL.md` before changing
  frontend code and follow its relative reference links as needed.
- Follow target-repo conventions first.
- Preserve behavior while refactoring.
- Split large files by one responsibility at a time.
- Verify with the target repository's checks before claiming completion.
