# Jxhnny Refactor Patterns

Read [the canonical skill](../skills/jxhnny-refactor-patterns/SKILL.md) for
frontend refactors and follow its reference links as needed.

The skill instructions are shared across agents. `agents/openai.yaml` is
optional Codex UI metadata; other agents can read `SKILL.md` and `references/`
without interpreting that file.

Use `scripts/install-agent-instructions.sh` to install the complete skill and a
project instruction pointer into agents that do not discover skills natively.
